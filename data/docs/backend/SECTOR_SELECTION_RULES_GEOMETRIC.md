# 扇形区域选点的几何规则（vf1, vf2, vf3）

本文档以纯几何方式描述扇形区域代表点 vf1、vf2、vf3 的选取规则；不涉及具体实现、代码或向量排列，仅阐述从边界几何出发的抽象算法。

一、符号与设定
- 边界：封闭的简单多边形（或分段曲线）边界，由一串按顺/逆时针顺序排列的顶点构成。
- v0：参考点，为边界上的某一顶点。
- vr1、vl1：分别为 v0 的右侧与左侧直接相邻顶点（即与 v0 共边的两个顶点）。
- 方向与角度：以 v0 为极点、以从 v0 指向 vr1 的方向为零角，按顺时针测量角度。
- 夹角 θ：从零角（指向 vr1）到指向 vl1 的夹角，通常 θ∈(0,π]。
- 半径上限 R：以 v0 为圆心、半径 R 的圆所限定的“局部搜索范围”。R>0 与局部几何尺度同量级，用于保证代表点来自 v0 附近的局部区域。

二、扇区划分
- 在以 v0 为极点、角域为 (0, θ) 的扇形内，将角域等分为 3 个互不重叠且开口的扇区：
  - S1 = (0, θ/3)
  - S2 = (θ/3, 2θ/3)
  - S3 = (2θ/3, θ)
- 两端点 0 与 θ 不包含在任何扇区内（因此 vr1 与 vl1 不属于任何扇区）。

三、候选集合
- 从边界的所有顶点中剔除 v0；对每个剩余顶点 u，计算：
  - 距离 d(u) = ||u − v0||；
  - 角度 α(u) = 从 vr1 方向起按顺时针测得的 ∠(vr1方向, v0→u)。
- 顶点 u 仅在同时满足以下两项时视为“扇区候选”：
  - 角度条件：α(u) ∈ (0, θ)；
  - 距离条件：d(u) ≤ R。

四、扇形代表点的基本选择规则
- 对于每个扇区 Sk（k∈{1,2,3}）：
  1) 将所有候选顶点按 α(u) 是否落入 Sk 归类；
  2) 若 Sk 内存在候选顶点，则选取距离 d(u) 最小的顶点作为该扇区代表点 vfk；
  3) 若存在距离并列，可采用下列任一稳定几何准则打破并列（任选一种即可）：
     - 角度居中性：优先选择其角度更接近扇区中心角 ck=((2k−1)/6)·θ 的顶点；
     - 角度有序性：在保证三个代表点角度严格增序（α(vf1)<α(vf2)<α(vf3)）的前提下选择；
     - 轮廓平滑性：优先选择使三个代表点与 v0 构成更均匀角度间隔的方案。
  4) 若 Sk 内不存在满足条件的顶点，则该扇区“暂时无代表点”。系统可选择保持为空，或采用下述覆盖规则填充。

五、中线相交覆盖规则（可选增强）
为增强代表点对“局部边界几何”的刻画，允许以下覆盖策略：
- 定义“中线射线”：从 v0 沿角平分方向（θ/2）发出，并限制在长度 R 内的半直线；
- 若该射线与边界在非端点处发生相交，记最近相交点到 v0 的距离为 d_bis；
- 若满足以下任一条件，则触发覆盖：
  - S2（中间扇区）当前无代表点；
  - 或 S2 的代表点存在，但 d_bis 严格小于该代表点到 v0 的距离；
- 触发后，以“相交边”为中心，选取其两端顶点及其在边界顺序上的一个相邻顶点，共 3 个相邻的边界顶点，按其角度 α 从小到大依次对应于 S1、S2、S3 的代表点（即 vf1、vf2、vf3）。
- 直观解释：若沿角平分方向更快“撞到边界”，则以相交边附近的连续三个顶点作为代表，能更稳定地反映局部边界形状与尺度。

六、排除与一致性保证
- 由于扇区端点开口，vr1（α=0）与 vl1（α=θ）不会被选为任何扇区的代表点；
- 代表点始终位于角域 (0, θ) 内，且到 v0 的距离不超过 R；
- 采用覆盖规则时，所取的三个顶点来自相交边及其邻近顶点，也自然满足上述角度与距离约束（除非 θ 极小导致退化，见下节）。

七、退化与边界情形的建议处理
- θ 过小：当 θ 接近 0 时，三个扇区可能高度重叠或退化，可降低对“三等分”的刚性要求，或直接采用覆盖规则确定代表点；
- 稀疏边界：若某扇区内缺乏满足 d(u)≤R 的顶点，可适当增大 R，或保持该扇区无代表点，由后续策略（如插值或平滑）处理；
- 并列距离：并列打破准则建议在整个系统中保持一致，以保证跨步稳定性与可重复性。

八、小结
- vf1、vf2、vf3 是在 v0 附近角域 (0, θ) 内、半径不超过 R 的“最近边界顶点”在三个等分扇区中的代表；
- 开口扇区与半径约束共同确保代表点既不等同于 v0 的直接相邻点（vr1、vl1），又忠实反映 v0 周围的几何分布；
- 中线相交覆盖规则为可选增强，可在复杂轮廓处提供更稳定、与轮廓更一致的代表。
